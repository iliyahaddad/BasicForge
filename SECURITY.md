# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in BasicForge, please report it by:

1. **Not** opening a public GitHub issue
2. creating a private security advisory on GitHub
3. Including:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will respond within 48 hours and will keep you informed of the progress towards a fix.

## Security Best Practices

- Keep your compiler and IDE up to date
- Only download BasicForge from official sources
- Verify checksums of downloaded binaries
- Do not run untrusted `.bf` files
